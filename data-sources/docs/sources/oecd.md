# OECD

Researched: 2026-03-19

## What it is

The OECD provides programmatic data access through APIs based on the `SDMX` standard.

## Access notes

- OECD APIs are free of charge.
- OECD explicitly notes that rate limiting is in place.
- OECD provides query-builder support and best-practice guidance.

## What makes OECD attractive for the course

- Good for a more advanced discussion of data standards and structured international data access.
- Useful complement if the course wants cross-country comparisons.

## What makes OECD awkward

- `SDMX` is a real standard, but it is not beginner-friendly.
- This is a better source for a later API extension than for the course backbone.

## Provisional course role

Use as a secondary international API source if needed.

# Arbetsformedlingen

Researched: 2026-03-19

## What it is

Arbetsformedlingen publishes open data and APIs for job advertisements, historical and real-time job data, labour-market forecasts, occupations, and skills.

## Access and licensing

- Open data and open APIs are free for anyone to use.
- Some partner APIs require authentication, but the open job-ad data does not.

## Job-ad data found so far

- `JobSearch API` for current ads in JSON.
- `Historiska platsannonser API` for ads from 2016 onward once they have been unpublished.
- Historical job-ad file with all ads since 2006.
- Historical file is continuously updated and contains about 6.9 million ads.
- Historical ads are enriched with skills and include remote-work information.

## What makes Arbetsformedlingen attractive for the course

- Strongest source for text and LLM tasks.
- Natural for strings, dates, occupations, skills, and classification.
- Excellent bridge from structured data work to later LLM-supported data processing.
- Still economically relevant, unlike generic text demos.

## What makes Arbetsformedlingen awkward

- Documentation and operational complexity are noticeably higher than for SCB.
- The volume is too large for an early-course backbone unless the course supplies curated extracts.
- The source encourages students to wander into API complexity before they are ready.

## Provisional course role

Use later in the course for APIs, text processing, and LLM-based assignments.
Do not use it as the early-course backbone.

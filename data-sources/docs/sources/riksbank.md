# Riksbank

Researched: 2026-03-19

## What it is

The Riksbank publishes APIs for rates, exchange rates, and macro forecasts, and also publishes speeches, press releases, and RSS feeds.

## Access and API notes

- The rates and exchange-rate API is a REST API and is free to use.
- It is rate-limited by IP address, with optional registration for heavier usage.
- The old SOAP API for rates and exchange rates was closed on 2024-05-27.
- The forecasts/outcomes API is also REST-based, free, and rate-limited.
- Forecasts/outcomes are available from 2020 onward.

## Text access

- The Riksbank provides RSS feeds for press releases, notices, calendar events, speeches, and minutes.
- Full speeches and other publications are available on the website.

## What makes Riksbank attractive for the course

- Strong source for a macro/finance-flavoured API lecture.
- Useful for dates, time series, and publication workflows.
- Good later-course text source for classification or summarization.

## What makes Riksbank awkward

- Narrower than a municipality backbone.
- Better for a specialised macro/finance story than for a broad data-science workflow course.

## Provisional course role

Use as a strong optional source for an API/text module, especially if the course wants a macro/finance example.

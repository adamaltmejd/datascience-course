# World Bank

Researched: 2026-03-19

## What it is

The World Bank Indicators API provides broad programmatic access to international development and macro indicators.

## Access notes

- The API provides access to nearly 16,000 indicators.
- It covers more than 45 databases.
- API keys and other authentication are no longer necessary.
- Version 2 replaces version 1 and requires `v2` in the call.

## What makes the World Bank attractive for the course

- Very stable and easy to explain.
- Good fallback source for a simple API lecture.
- Broad historical coverage.

## What makes the World Bank awkward

- Too generic for the identity currently emerging for the course.
- Cleaner and less locally meaningful than Swedish municipal sources.
- Weak fit for the later text/LLM part of the course.

## Provisional course role

Fallback API source, not preferred backbone.

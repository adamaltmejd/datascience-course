# Data Source Notes

These notes record source-specific findings for the 2026 course redesign.

Current working view:

- `SCB` is the strongest backbone source.
- `Kolada` is the strongest municipal complement.
- `Valmyndigheten` is a clean optional join partner.
- `Arbetsformedlingen` is best used later for text, APIs, and LLM work.
- Inflation and consumption is a plausible later module, but not a finished dataset yet.

# Data Sources

Course data and source notes for the 2026 redesign.

## Layout

- `data/municipal-opportunity-panel/`: frozen municipality-year teaching panel and its rebuild script
- `data/dogs/`: small dog-shelter files used in the wrangling lectures
- `docs/sources/`: source-specific notes, including sources that were considered but not turned into datasets

## Current Datasets

- `data/municipal-opportunity-panel/municipal_opportunity_panel_2016_2023.csv`
- `data/dogs/dog_inventory.csv`
- `data/dogs/dog_breeds.csv`
- `data/dogs/dog_sales.csv`

See each dataset folder for a dataset-specific `README.md`.
